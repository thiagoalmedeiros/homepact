# HomePact

An open-source platform for small home builders and the independent contractors they work with.

## Why

Small builders and trades often run jobs on spreadsheets and text messages. Quotes, contracts
and payments get messy, and mistakes are easy to make. HomePact puts it all in one place.

## What it does today

- Plans, proposals and revisions
- Purchase agreements with signatures and stored PDFs
- Deposits and receipts
- Change orders after signing
- Many builders on one install, each with its own private data

## Where it's going

A network of independent contractors:

- Builders post jobs and contractors bid
- The winning contractor signs a contract and bills for completed work
- One login per contractor that shows only what each builder shared with them
- Contractor payments that are central, auditable and add up to the cent

## Quick start

Needs Node.js 22. No Docker or database to install.

```bash
npm install
npm run dev     # starts the app with demo data
npm run check   # lint, typecheck and all tests
```

Full setup, testing, roles and conventions: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
